# CookieForge

Offline, open-source cookie cutter and embossing stamp designer.

## Project status

Bootstrap in progress. The first milestone imports the upstream Cookie Cutter Designer baseline without functional changes, then verifies its checks and tests before building an advanced contour and relief editor.

## Upstream

Based on [Cookie Cutter Designer](https://github.com/razorglyon/cookie-cutter-designer) by razorglyon (MIT license). Original copyright and license notices must be preserved.

## Roadmap

1. Import upstream source and retain license and attribution.
2. Verify type checks, tests, build and export smoke tests.
3. Establish an unchanged baseline before feature development.
4. Add per-contour editing and relief controls on a feature branch.
5. Package for offline Windows use, then evaluate Android.

No printer safety or food-contact certification is implied.
